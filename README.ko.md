# 인천 e음 캐시백 정책 시뮬레이션

[English](README.md) · [사례 연구](PORTFOLIO.ko.md)

인천 e음카드의 군·구별 일별 결제금액을 예측하고, 정해진 예산 안에서 캐시백 일정을 비교합니다. (e음카드는 인천시 지역화폐 결제 카드이고, 캐시백은 시가 소비를 늘리려고 주는 혜택입니다.)

**의사결정 질문.** 2024년 예산 2,000억 원으로 1년 중 두 달만 캐시백을 올릴 수 있다면, 캐시백 1원당 소비를 가장 많이 끌어내는 두 달은 언제인가?

**결과.** 두 달을 고르는 C(12,2) = 66개 조합을 모두 비교합니다. 상위 5개 조합은 모두 4월·6월·9월 중 하나 이상을 포함하며, 1위는 4월+6월입니다(보고서 ROI 지수 76.433, 5위는 73.293). 검토할 후보 시기 목록이며, 실제 정책 효과를 측정한 결과는 아닙니다.

**수상과 역할.** 2025 인천대학교 산학 캡스톤디자인 경진대회 금상(2025.07.01). 4인 팀의 팀장(최종 보고서 표지).

## 데이터와 가정

- 10개 군·구의 일별 결제금액에 연령대별 인구, 업종별 결제금액, CD 수익률, 소비자심리지수(CSI), 캐시백 비율, 충전·결제 건수를 결합했습니다. 학습 데이터는 2020~2023년입니다(포함하지 않음).
- Low-Pass Filter(LPF)로 추세와 노이즈를 분리합니다. Hurst 지수 0.79~0.86(노트북 `03_feature_engineering`)은 지속성 있는 시계열을 뜻하며, 시차 추세 변수의 근거가 됩니다.
- 배경: 2022년 7월 캐시백이 10%에서 5%로 내려간 뒤 8월 결제금액이 전월 대비 24.92% 줄었습니다(보고서 그림).

## 시나리오 설계

1. 군·구마다 캐시백 조건별 LightGBM 모델 두 개를 학습합니다. 보고서는 이를 '5% 모델'과 '10% 모델'이라고 부르며, 데이터상으로는 가맹점 요율 조합 10%/5%와 10%/10%에 해당합니다.
2. 66개 조합마다 상향한 두 달에는 10% 모델을, 나머지 열 달에는 5% 모델을 적용하고, 각 달의 예측을 다음 달에 반영합니다.
3. 지급한 캐시백을 2,000억 원 예산에서 차감합니다. ROI 지수는 예측 소비 증가분을 지급 캐시백과 비교하고, 남은 예산 비율을 곱한 값입니다.

## 결과

상위 5개 조합(최종 보고서 3.7절):

| 순위 | 상향 월 | 보고서 ROI 지수 |
|---:|---|---:|
| 1 | 4월, 6월 | 76.433 |
| 2 | 4월, 9월 | 76.154 |
| 3 | 5월, 6월 | 75.817 |
| 4 | 6월, 9월 | 74.305 |
| 5 | 6월, 11월 | 73.293 |

시뮬레이션에 쓴 예측의 오차(LightGBM, 2024년 이전 데이터로 학습하고 2024년 데이터로 평가; 보고서 표, 노트북 `99_draft_2`):

| 범위 | MAPE |
|---|---|
| 군·구 × 조건 20개 구간 | 8.06% ~ 66.22% |
| 15% 이하 구간 | 20개 중 13개 |
| 오차가 가장 큰 구간(10%/10% 조건) | 강화군 66.22%, 연수구 44.26% |

보고서는 이를 '대부분 지역에서 MAPE 10~15% 이내'로 요약합니다.

## 실행

CLI는 휴대용 기본선(군·구별 CatBoost, 시간순 80/20 분할)이며, 보고서의 LightGBM 모델이나 ROI 시뮬레이션이 아닙니다.

```powershell
pip install -r requirements.txt

python run_pipeline.py `
  --input-csv data\merged.csv `
  --region-col "<지역 컬럼>" `
  --date-col "<날짜 컬럼>" `
  --target-col "<소비 타깃 컬럼>"
```

피처, 군·구별 지표, 모델을 `results/`에 쓰며, 전체 옵션은 `--help`로 확인합니다.

## 한계

- 인과 효과가 아닙니다. 순위는 10% 조건 모델이 요율 상향을 설명한다는 가정에 기대며, 24.92% 감소는 전후 비교 수치입니다.
- 예측 변수에 당일 결제·충전 건수가 들어 있어, MAPE는 그날의 활동량을 알 때의 적합도이며 사전 예측 성능이 아닙니다.
- 상위 5개 ROI 값의 차이는 약 4% 이내로, 대부분 구간의 예측 오차보다 작습니다.
- ROI 표는 보고서 기준이며 원본 데이터 없이 다시 만들 수 없습니다. 결합 CSV 없이는 `--help`만 실행됩니다.
- 그림 2의 CatBoost 점수는 같은 구간을 early stopping과 평가에 함께 써서 낙관적입니다.
- 라이선스 파일이 없습니다(기본적으로 모든 권리 보유). 보고서 PDF는 팀의 경진대회 제출 문서입니다.
