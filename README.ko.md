# 인천 e음 캐시백 정책 시뮬레이션

[English](README.md) · [사례 연구](PORTFOLIO.ko.md)

인천 e음카드의 군·구별 일별 결제금액을 예측하고, 정해진 예산 안에서 캐시백 일정을 비교합니다. (e음카드는 인천시 지역화폐 결제 카드이고, 캐시백은 시가 소비를 늘리려고 주는 혜택입니다.)

**문제.** 2024년 예산 2,000억 원으로 1년 중 두 달만 캐시백을 올릴 수 있다면, 캐시백 1원당 소비를 가장 많이 끌어내는 두 달은 언제일까요?

**결과.** 두 달을 고르는 C(12,2) = 66개 조합을 모두 비교했습니다. 상위 5개 조합은 모두 4월·6월·9월 중 하나 이상을 포함하며, 1위는 4월+6월로, ROI 지수(예측 소비 증가분을 지급 캐시백과 비교하고 남은 예산 비율을 곱한 값)가 76.433입니다. 5위는 73.293입니다.

**범위.** 검토할 후보 시기 목록이며, 실제 정책 효과를 측정한 결과는 아닙니다. 상위 5개 조합의 차이(약 4%)는 모든 구간의 예측 오차(MAPE 8.1%~66.2%)보다 작습니다. 학습 데이터는 포함되어 있지 않으며, `python run_pipeline.py --help`로 확인할 수 있는 것은 ROI 시뮬레이션이 아닌 기준 CatBoost CLI입니다.

**수상과 역할.** 2025 인천대학교 산학 캡스톤디자인 경진대회 금상(2025.07.01). 4인 팀 팀장.

## 데이터와 가정

- 10개 군·구의 일별 결제금액에 연령대별 인구, 업종별 결제금액, CD 수익률, 소비자심리지수(CSI), 캐시백 비율, 충전·결제 건수를 결합했습니다. 학습 데이터는 2020~2023년입니다(저장소에는 미포함).
- Low-Pass Filter(LPF)로 추세와 노이즈를 분리합니다. 군·구별 Hurst 지수 0.79~0.86(노트북 `03_feature_engineering`)은 시계열에 지속성이 있다는 뜻이며, 시차 추세 피처를 쓰는 근거가 됩니다.
- 배경: 2022년 7월 캐시백이 10%에서 5%로 내려간 뒤 8월 결제금액이 전월 대비 24.9% 줄었습니다.

## 시나리오 설계

1. 군·구마다 캐시백 조건별 LightGBM 모델 두 개를 학습합니다. 보고서는 이를 '5% 모델'과 '10% 모델'이라고 부르며, 데이터상으로는 가맹점 요율 조합 10%/5%와 10%/10%에 해당합니다.
2. 66개 조합마다 상향한 두 달에는 10% 모델을, 나머지 열 달에는 5% 모델을 적용하고, 각 달의 예측을 다음 달에 반영합니다.
3. 지급한 캐시백을 2,000억 원 예산에서 차감합니다. ROI 지수는 예측 소비 증가분을 지급 캐시백과 비교하고, 남은 예산 비율을 곱한 값입니다.

## 결과

상위 5개 조합:

| 순위 | 상향 월 | ROI 지수 |
|---:|---|---:|
| 1 | 4월, 6월 | 76.433 |
| 2 | 4월, 9월 | 76.154 |
| 3 | 5월, 6월 | 75.817 |
| 4 | 6월, 9월 | 74.305 |
| 5 | 6월, 11월 | 73.293 |

시뮬레이션에 쓴 예측의 오차(LightGBM, 2024년 이전 데이터로 학습하고 2024년 데이터로 평가, 노트북 `99_draft_2`):

| 범위 | MAPE |
|---|---|
| 군·구 × 조건 20개 구간 | 8.1% ~ 66.2% |
| 15% 이하 구간 | 20개 중 13개 |
| 오차가 가장 큰 구간(10%/10% 조건) | 강화군 66.2%, 연수구 44.3% |

보고서는 이를 '대부분 지역에서 MAPE 10~15% 이내'로 요약합니다.

## 실행 방법

CLI는 데이터만 바꿔 실행할 수 있는 기준 파이프라인(군·구별 CatBoost)이며, 위의 LightGBM 모델이나 ROI 시뮬레이션이 아닙니다. 군·구마다 날짜순으로 나눠 마지막 20%로 RMSE·MAPE를 평가하고, 이 구간은 학습과 early stopping에 쓰지 않습니다. 나머지 학습 기간의 마지막 10%를 early stopping 구간으로, 그 앞부분을 학습에 씁니다. 따라서 그림 2의 탐색과 달리 평가 구간에 맞춰 조정된 점수가 아닙니다.

```powershell
pip install -r requirements.txt

python scripts/smoke_test.py   # 합성 2개 구 데이터로 분할 확인

python run_pipeline.py `
  --input-csv data\merged.csv `
  --region-col "<지역 컬럼>" `
  --date-col "<날짜 컬럼>" `
  --target-col "<소비 타깃 컬럼>"
```

피처, 군·구별 지표(분할별 행 수, best iteration, RMSE, MAPE), 모델을 `results/`에 저장하며, 전체 옵션은 `--help`로 확인합니다. 스모크 테스트는 데이터가 필요 없고, catboost가 없으면 기록용 대체 모델로 분할만 확인합니다. 노트북은 Google Colab(Python 3.11: `02`, `03`, `99_draft_2`)과 로컬 Python 3.12.4 환경(`01`, `04`~`08`)에서 실행했습니다. `requirements.txt`는 numpy·scipy·scikit-learn을 `03` 노트북에 기록된 버전으로 고정했고, 원래 버전 기록이 없는 pandas는 2026-11 점검 환경 버전으로 고정, catboost는 고정하지 않았습니다.

## 한계

- 인과 효과가 아닙니다. 순위는 10% 조건 모델이 요율 상향을 설명한다는 가정에 기대며, 24.9% 감소는 전후 비교 수치입니다.
- 피처에 당일 결제·충전 건수가 들어 있어, MAPE는 그날의 활동량을 알 때의 적합도이지 사전 예측 성능이 아닙니다.
- 상위 5개 ROI 값의 차이는 약 4% 이내로, 대부분 구간의 예측 오차보다 작습니다.
- 결합된 학습 데이터가 저장소에 없어 ROI 표를 이 저장소만으로 다시 만들 수 없습니다.
